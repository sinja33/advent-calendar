# 🎄 Advent Calendar - A Christmas Gift

A beautiful, interactive advent calendar website with date-locked windows revealing personal photos throughout December.

## ✨ Features

- 25 windows for December 1-25
- Date-locked system (can't open windows early!)
- Beautiful romantic Christmas design
- Animated snow and glowing effects
- Full-screen photo viewer
- Mobile responsive
- Automatic date checking

## 🎁 Perfect For

- Romantic Christmas countdown
- Surprise photo reveals
- Personal gift for your partner
- Creative way to share memories

## 📸 Customization

Replace the placeholder images with your own photos and add personal captions for each day.

See `INSTRUCTIONS.md` for detailed customization guide.
See `DEPLOYMENT-GUIDE.md` for step-by-step deployment to GitHub Pages.

## 🚀 Quick Start

```bash
npm install
npm start
```

Opens at `http://localhost:3000`

## 📦 Deploy

```bash
npm run deploy
```

Deploys to GitHub Pages automatically.
